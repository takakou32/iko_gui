# IKO GUI Application

汎用的なプロセス実行・管理GUIアプリケーションです。
複数のバッチファイル実行、ファイル移動、データ変換などの工程を、ページ（ステップ）ごとに管理・実行できます。

## 主な機能

1.  **ウィザード形式の工程管理**
    *   複数の工程（Page 1 ～ Page 4+）を順を追って実行できます。
    *   各ページは特定の業務（例：新旧サーバー移行、データ変換、DBロード等）に対応しています。

2.  **編集モード (Edit Mode)**
    *   画面左下の「編集モード」ボタンで切り替え可能。
    *   **ON**: 設定変更モード。パスの変更、チェックボックスのON/OFF、ボタン名の変更などが可能です。
    *   **OFF**: 実行モード。誤操作防止のため、設定変更はロックされます。

3.  **プロセス制御**
    *   **有効/無効切り替え**: 各プロセスの「Enable/Disable」チェックボックスで、実行の可否を制御できます。
    *   **自動無効化**: プロセス実行が正常完了すると、自動的にそのプロセスは無効化（チェックOFF）され、二重実行を防止します。
    *   **グレーアウト**: 無効化されたプロセスはグレーアウト表示され、視覚的に状態が分かります。

4.  **エクスプローラ連携**
    *   編集モード**OFF**時、パスが表示されているテキストボックスをクリックすると、そのフォルダをエクスプローラで開くことができます。
    *   編集モード**ON**時は、クリックすると「フォルダ選択ダイアログ」が開き、パスを変更できます。

5.  **ログ管理**
    *   実行ログは画面下部にリアルタイム表示されます。
    *   「ログ確認」ボタンで、各プロセスの詳細ログファイルを直接開くことができます。
    *   共通のログ格納先を設定・管理できます。

## 画面構成

### ヘッダー
*   現在のページタイトルとステップ説明を表示。
*   `<` `>` ボタンでページを切り替えます。

### メインエリア (プロセス一覧)
ページごとに定義されたプロセスが一覧表示されます。
*   **名前**: プロセス名（編集モードで変更可）。
*   **パス欄**: 関連するファイルやフォルダのパス。
    *   *通常時クリック*: エクスプローラで開く。
    *   *編集時クリック*: 参照ダイアログを開く。
*   **操作ボタン**:
    *   **実行/移動/取込**: 処理を実行します（無効時は押せません）。
    *   **ログ確認**: 処理結果のログファイルを開きます。
*   **チェックボックス**:
    *   上段: 削除等の管理用（一部ページ）。
    *   下段: **有効/無効切り替え**。実行可否を制御します。

### フッター (共通設定)
*   **編集モード切り替えボタン**: 設定変更を行う際に使用します。
*   **ログ格納設定**: ログファイルの保存先を指定します。

## 動作環境
*   OS: Windows 10/11
*   必須: PowerShell 5.1以上, .NET Framework 4.7.2以上

## 設定ファイル
`config/json/` フォルダ内のJSONファイルで各ページの構成を定義しています。
*   `config.json`: 全体構成とページ定義
*   `pageX.json`: 各ページのプロセス詳細
