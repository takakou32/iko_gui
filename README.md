# IKO GUI Application

汎用的なプロセス実行・管理GUIアプリケーションです。
複数のバッチファイル実行、ファイル移動、データ変換などの工程を、ページ（ステップ）ごとに管理・実行できます。

## 使用方法・機能解説

#### 【実行方法】（一般利用者用）
1.  **起動**: `run.bat` を実行します。
2.  **実行**: 編集モードが「OFF」であることを確認し、ボタンを順番に押下します。
    - 正常完了したプロセスはボタンが自動的に無効化され、二重実行を防止します。
3.  **確認**: 
    - 進行状況は画面下部のログで確認。
    - パス欄やログ格納元をクリックすると、エクスプローラでその場所を確認できます。

### 2. 各画面・機能の詳細

#### ページ構成と工程管理
*   `<` `>` ボタンで工程（Page 1 ～ Page 4等）を切り替えます。
*   各ページに配置された「タスク名」とそれに対応する操作ボタン（実行、移動、取込、変換等）で一連の業務を進めます。
*   **ログ格納元（フッター）**: ページごとに独立した設定となっており、その工程に関連するログの保存先を指定します。

#### 編集モード (Edit Mode) の役割
*   **ON (設定モード)**: 画面のロックが解除され、パスの変更やタスク名の編集、工程の表示/非表示（タスク名の左側のチェック）の設定が可能になります。
*   **OFF (実行モード)**: 設定が固定され、誤動作を防ぐための実行専用状態になります。

#### プロセス制御と自動ガード
*   **有効/無効**: チェックが入っているプロセスのみ実行可能です。
*   **自動無効化**: 操作が正常に完了すると、対象のボタンが自動的に無効化（グレーアウト）され、同じ処理を二度行うミスを防ぎます。

#### エクスプローラ連携機能
*   編集モード**OFF**時にパス欄（テキストボックス）やログ格納元をクリックすると、エクスプローラを開きます。
    - パスがフォルダならそのフォルダを開き、ファイルなら親フォルダを開いて対象を選択状態にします。

#### ログ・設定管理
*   **ログ確認**: ボタンから個別の詳細ログを表示できます。
*   **相対パス保存**: 設定したパスは、環境が変わっても動作するよう可能な限り相対パスで管理されます。

## 画面構成

### ヘッダー
*   現在のページタイトルとステップ説明を表示。
*   `<` `>` ボタンでページを切り替えます。

### メインエリア (プロセス一覧)
ページごとに定義されたプロセスが一覧表示されます。
*   **タスク名**: プロセス名（編集モードで変更可）。
*   **パス欄**: 関連するファイルやフォルダのパス。
    *   非編集モード時にクリックでエクスプローラ表示、編集モード時にクリックでパス選択。
*   **操作ボタン**:
    *   **実行/移動/取込/変換**: 処理を実行します。実行中はボタンが一時的に無効化されます。
    *   **移動設定/参照**: 編集モード時のみ表示。処理に使用するバッチファイルや移動ルールを設定します。
    *   **ログ確認**: 処理結果のログファイルを開きます。
*   **チェックボックス**:
    *   左側（編集時のみ）: 工程の表示/非表示（Enable Control）を切り替えます。
    *   右側/下段: **有効/無効切り替え**。チェックが入っている場合のみ実行可能です。

### フッター (共通設定)
*   **編集モード切り替えボタン**: 設定変更を行う際に使用します。
*   **ログ格納設定**: ログファイルの保存先（ログ格納元）を指定します。

## 動作環境
*   OS: Windows 10/11
*   必須: PowerShell 5.1以上, .NET Framework 4.7.2以上

## 設定ファイル
`config/json/` フォルダ内のJSONファイルで各ページの構成を定義しています。
*   `config.json`: 全体構成とページ定義
*   `pageX.json`: 各ページのプロセス詳細
